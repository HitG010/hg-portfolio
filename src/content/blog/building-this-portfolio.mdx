## Code blocks

Highlighting happens at build time, so no highlighter is shipped to the
browser:

```jsx
function useMediaQuery(query) {
  const subscribe = useCallback(
    (onStoreChange) => {
      const mq = window.matchMedia(query);
      mq.addEventListener("change", onStoreChange);
      return () => mq.removeEventListener("change", onStoreChange);
    },
    [query]
  );

  return useSyncExternalStore(
    subscribe,
    () => window.matchMedia(query).matches,
    () => false
  );
}
```

## Writing a new post

Add a `.mdx` file to `src/content/blog/`. The frontmatter block at the top
drives the index page:

```yaml
---
title: "Your title"
date: "2026-08-01"
summary: "One or two sentences for the index."
tags: ["react"]
readingTime: "5 min"
draft: true # omit or set false to publish
---
```

Set `draft: true` while you work on it and the post stays in the repo but off
the site.
